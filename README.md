## Descripción General

### Problematica a resolver
  En el mundo de videojuegos hay muchos temas que se deben de abordar, además de establecer en el jugador un mecanica de entretenimiento, El objetivo principal es entretener al jugador mediante un enfoque en el gameplay desafiante para este mismo, asi pues establecer en si una narrativa que incentica al usuario a seguir investigando por este misteriosos mundo que hemos desarrollado.

### Público
 El público al que va dirigido es de personas mayores a 18 años,ya que establece una conexión con los jugadores más veterano quienes no solamente buscan un medio de entretenimiento, sino más que nada un desafío y un enfoque importante a la narrativa y ambientación tomando en cuenta hacia un miedo a lo desconocido y controversial.

 ### Contexto
  En un principio este proyecto se desarrolla en un ambiente institucional, sin embargo, nuestro objetivo va mas haya, a largo mediano plazo queremos tener un videojuego mucho mejor desarrollado tomando en cuenta todos lo puntos de vista del público y expertos en el tema, formando una comunidad que genere un interes en la elaboración de este titulo.

  ### Objetivo General
   Plasmar en el usuario un videojuego de calidad elaborado por estudiantes apasionados en la industria mediante un gameplay desafiante, narrativa intensa y buena ambientación. 
   
   ### Prologo 
 Acompaña al caballero anonimo quien tiene el objetivo de descubrir como eliminar la maldición de la luna roja para salvar a su familia de un tragico destino, te enfrentaras a monstruos inimaginables y criatura fuera de la comprensión humana, descubriras los misterios que la oscuridad oculta.

- Lenguajes: HTML, JavaScript

- Herramientas adicionales: VS Code, Git, Github
  



### Estructura del Proyecto
El proceso de desarrollo en equipo empieza a establecer diferentes retos para la creacion del videojuego, establecer un enfoque en de Gameplay preciso y divertido para el usuario es prioridad para que cumpla el objetivo del proyecto el cual es entretener.

En esta primera etapa, nos enfocamos en crear un estilo visual llamativo, posteriormente, establecer mecanicas basicas del jugador, las cuales son:

- Movimiento fluido player con sus sprite.
- Ataque básico del player.
- Deslice del player mas mayor fluides en gameplay.
- IA básica del enemigo.
- Atáque cargado del player.
- Curacion del player.

Entre el sistema visual se establece los siguiente:
 
- Un sistema de assets con estilo visual agradable a la vista.
- Sprites con un sistema de 5 a 8 frames entre acciónes.
- Sistema de luces para mayor impacto visual.

#### Posteriomente establezco la estructura del proyecto:

[src](https://github.com/AlexAntonio29/red-moon/tree/main/src) contiene el codigo del proyecto, todo el algoritmo la cual esta subdivividido en mas carpetas.


[sounds](https://github.com/AlexAntonio29/red-moon/tree/main/sounds) Contiene los sonidos utilizados para la elabaracion del juegos, las subdivisiones son una conexion entre los diferentes objetos que en esta se establecen.


[node_modules](https://github.com/AlexAntonio29/red-moon/tree/main/node_modules) Es donde se almacena los archivos importantes del motor phaser.

[diagramas](https://github.com/AlexAntonio29/red-moon/tree/main/diagramas) Contiene los diagramas que se utilizaron para la elaboración del proyecto.

[assets](https://github.com/AlexAntonio29/red-moon/tree/main/assets) Contiene los sprites y archivos JSON( que se utilizan para la elaboración de los mapas mapa), estos son representados por imagenes PNG sin fondo para la elaboracion de contenido visual y la iluminación.

[DOCUMENTACIÓN](https://github.com/AlexAntonio29/red-moon/tree/main/DOCUMENTACION%20REDMOON) Contiene la documentacion del proyecto.


### Instalación y configuración
El proceso de uso de este proyecto es sencillo pero si requiere de ciertos pasos para su buen uso.

1. Instalar [git](https://git-scm.com/)
2. Instalar [node.js](https://nodejs.org/es) para poder utilizar el framework de phaser
3. En terminal Bash agregar el comando git clone https://github.com/AlexAntonio29/red-moon.git
4. Abrir Visual Studio e instalar la extensión [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer)
5. Ejecutar el live Server presionando la texto en la parter inferior de visual Studio Code.
6. Jugar.
